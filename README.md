# Бизнес-школа Proactive · операционка

Разработки для операционной работы бизнес-школы: учёт задач по плану запуска курсов, уведомления команде,
в перспективе — собственный трекер задач.

## Что здесь

| Папка | Что |
|---|---|
| [`bot/`](bot/) | Telegram-бот @proactive_school_bot (Google Sheets + Apps Script). Этап 1: уведомления исполнителям и утверждающим по статусной таблице; посторонним (клиентам) бот пока отвечает приветствием школы. Инструкция по установке — [`bot/README.md`](bot/README.md) |

## Статусная таблица задач

Задачи плана ведутся в Google-таблице, доступ к ней есть у команды. Листы:

- **Сводка** — сколько задач готово, просрочено и сколько процентов плана выполнено к концу недели; разрезы по отделам и неделям, просрочки по исполнителям, задачи в «Риске».
- **Задачи** — по строке на задачу: ID, неделя, срок (воскресенье недели), отдел, продукт, исполнитель, статус, отклонение от плана, критерий готовности, RACI.
- **Команда** — роли, Telegram и правила, по которым бот узнаёт людей в задачах.
- **Справочник** — статусы, коды отделов в ID, утверждающие по умолчанию, что получает каждая роль RACI.
- **Журнал бота** — появится после включения бота: все отправленные уведомления.

Статусы: «Не начато», «В работе», «Готово», «Риск», «Отменено». Столбцы «Неделя», «Срок», «Относительно плана» и «Отклонение, дн» считаются формулами.

## Данные

Репозиторий публичный, поэтому исходный план, данные команды и ссылки на рабочие таблицы сюда не кладём.
